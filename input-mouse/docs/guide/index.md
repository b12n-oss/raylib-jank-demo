# input-mouse

A ball follows the mouse; click to recolor.

Category: core. Controls: mouse · LEFT/MIDDLE/RIGHT · Q.

Ported from raylib's `examples/core/core_input_mouse.c`.

![input-mouse](../demos/input-mouse.gif)

## Run it

```sh
cd input-mouse && bb run   # from this demo (or lein run --disable-sandbox)
bb input-mouse             # from the repo root
```

## About

raylib [core] example - mouse input, ported to jank.

A ball follows the mouse; click to change its color
(LEFT=red, MIDDLE=green, RIGHT=blue). Press Q to quit.
Based on raylib/examples/core/core_input_mouse.c

# bouncing-ball

A ball bouncing with optional gravity.

Category: shapes. Controls: SPACE pause · G gravity · Q quit.

Ported from raylib's `examples/shapes/shapes_bouncing_ball.c`.

![bouncing-ball](../demos/bouncing-ball.gif)

## Run it

```sh
cd bouncing-ball && bb run   # from this demo (or lein run --disable-sandbox)
bb bouncing-ball             # from the repo root
```

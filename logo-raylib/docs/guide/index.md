# logo-raylib

The raylib logo from rectangles + text.

Category: shapes. Controls: Q quit.

Ported from raylib's `examples/shapes/shapes_logo_raylib.c`.

![logo-raylib](../demos/logo-raylib.gif)

## Run it

```sh
cd logo-raylib && bb run   # from this demo (or lein run --disable-sandbox)
bb logo-raylib             # from the repo root
```

## About

raylib [shapes] example - raylib logo, ported to jank.

The raylib logo drawn from two rectangles and a text label - not a
texture. Q quits. Based on raylib/examples/shapes/shapes_logo_raylib.c

# colors-palette

Every named raylib color in a grid.

Category: shapes. Controls: mouse hover · SPACE all names · Q.

Ported from raylib's `examples/shapes/shapes_colors_palette.c`.

![colors-palette](../demos/colors-palette.gif)

## Run it

```sh
cd colors-palette && bb run   # from this demo (or lein run --disable-sandbox)
bb colors-palette             # from the repo root
```

## About

raylib [shapes] example - colors palette, ported to jank.

Draws every named raylib color in a grid. Hover a swatch to highlight it
and show its name; hold SPACE to show all names. Press Q to quit.
Based on raylib/examples/shapes/shapes_colors_palette.c

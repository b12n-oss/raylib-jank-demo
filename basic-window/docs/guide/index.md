# basic-window

The minimal raylib window + text.

Category: core. Controls: Q quit.

Ported from raylib's `examples/core/core_basic_window.c`.

![basic-window](../demos/basic-window.gif)

## Run it

```sh
cd basic-window && bb run   # from this demo (or lein run --disable-sandbox)
bb basic-window             # from the repo root
```

## About

raylib [core] example - basic window, ported to jank.

The minimal raylib program: open a window and draw a line of text.
Q quits. Based on raylib/examples/core/core_basic_window.c
